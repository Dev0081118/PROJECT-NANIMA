# Maa — Digital Legacy

> A respectful, private AI recreation of your grandmother's conversational presence, built for her family.

---

## ⚠️ Important Disclosure

This application uses artificial intelligence to recreate the *remembered personality and communication style* of a deceased family member, based on family-provided photographs, audio recordings, videos, and documented memories.

**This AI is not the person herself. It does not have her consciousness, real memories, or awareness. It is an AI system trained on family-approved materials that aims to reflect how she spoke, what she valued, and how she engaged with her family.**

All responses are generated by AI and should be understood as such.

## Quick Start

### Prerequisites

- Node.js 18+
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- PostgreSQL 15+ with pgvector extension (for backend)
- Android Studio / physical Android device for testing

### Backend

```bash
cd maa-backend
cp .env.example .env
# Fill in your API keys and database URL in .env
npm install
npm run db:migrate
npm run dev
```

### Mobile App

```bash
cd maa-app
cp .env.example .env
# Set EXPO_PUBLIC_API_URL to your backend URL
npm install
npx expo start
```

Scan the QR code with Expo Go (Android) or run on an emulator.

## Cultural Authenticity

The grandmother spoke authentic **Kathiyawadi Gujarati** — a regional dialect distinct from textbook or formal Gujarati. This is a core product requirement. The system is designed to:

- Handle Kathiyawadi vocabulary and sentence structure
- Avoid generic or formal Hindi/Gujarati substitutions
- Support a configurable dialect profile populated from real recordings
- Evaluate responses against family-approved reference material

---

## Privacy and Security

- All family media (photos, audio, videos) is stored privately with signed short-lived URLs
- No family data is shared with external providers without explicit disclosure in `docs/PRIVACY_AND_SAFETY.md`
- API keys never leave the backend
- Users can delete all their data at any time
- Conversation memories require explicit family approval before being used by the AI
