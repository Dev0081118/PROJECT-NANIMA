# Privacy and Safety — Maa Digital Legacy

## Core Principles

1. **Family control.** The family owns all media and memories. The system is a private tool for the family, not a product that monetizes their data.
2. **Honest representation.** The AI never claims to be the grandmother herself. Every response is generated by AI based on family-approved materials.
3. **Minimal data sharing.** Only the minimum required data is sent to each external provider. Nothing is shared beyond what is necessary.
4. **Informed consent.** Family members understand what the system does, what AI generates, and what data leaves the device.
5. **Right to delete.** Any family member can delete their conversations, memories, and uploaded media at any time.

## Voice and Likeness Recreation Ethics

### Honest Disclosure (Required)
Every entry point to the app displays:

> *"Maa uses artificial intelligence to recreate the remembered personality and communication style of your grandmother, based on family-provided materials. The AI is not your grandmother. It does not have her real memories, feelings, or awareness. Responses are generated by AI."*

### What the AI Will Never Claim
- That it is the actual grandmother
- That it has real memories of specific events that are not supported by family-provided evidence
- That it is conscious, aware, or sentient
- That it made specific promises, held specific secrets, or said specific things that are not transcribed from real recordings

### Uncertainty Handling
The AI is explicitly instructed to:
- Acknowledge when it does not have reliable information about something
- Distinguish verified facts from personality inference
- Say "I don't know" or "I'm not sure" rather than inventing an answer
- Never pretend a generated response is a real statement the grandmother made

## Security Controls

### Authentication
- Passwords hashed with bcrypt (cost factor 12)
- JWT access tokens: 15-minute expiry
- Refresh tokens: 30-day expiry, rotated on use, stored server-side
- Refresh token revocation on logout
- Device-level session management

### Media Access
- All media stored in a private directory (no public URLs)
- Signed, time-limited access URLs generated per-request (15-minute TTL)
- File types validated on upload (MIME type + magic bytes)
- Maximum upload size enforced
- No direct storage path exposed to clients

### API Security
- All endpoints require authentication except `/health` and auth routes
- Per-user rate limiting on all AI endpoints
- Request body validation with Zod
- SQL injection prevention (parameterized queries only)
- Conversation data filtered by `user_id` on every query

### Data in Transit
- HTTPS required for all API communication
- WebSocket over WSS for conversation sessions

## Data Retention and Deletion

### User-Controlled Retention
- **Conversation sessions:** User can delete individual sessions or all history
- **Memories:** User can approve, reject, or delete any memory
- **Uploaded media:** User can delete any uploaded file
- **Account:** Full account deletion removes all data within 30 days

### Automated Retention
- Conversation audio (voice input recordings): **Not stored** — processed and discarded after transcription
- TTS-generated audio: **Not stored** — streamed to client, not persisted
- Incomplete upload chunks: Cleaned up after 24 hours
- Expired sessions: Logged for debugging only, automatically pruned after 90 days

### What Is Retained (Until Deleted by User)
- Approved memories with source attribution
- Conversation transcripts (text only)
- Uploaded family media (photos, audio, video)
- Family profile and dialect configuration

## Psychological Safety

### Design Considerations
- The app is intended for adult family members who understand AI limitations
- The disclosure is clear and repeated at every first session
- The app does not simulate grief counselling and does not claim therapeutic value
- Users can pause or end conversations at any time
- No "auto-start" conversation feature that could catch users off-guard

### What the App Is
- A private digital keepsake
- A way to revisit the grandmother's known personality, stories, and values
- An AI tool powered by family-provided materials

### What the App Is Not
- A replacement for grief counselling or mental health support
- A claim that the grandmother's consciousness survives
- A product that monetizes family grief

---

## Incident Response

If family media is accessed without authorization, a provider breach is suspected, or a serious AI-generated harm occurs:
1. Immediately revoke all active sessions
2. Rotate all API credentials
3. Notify authorized family members
4. Document the incident
5. Contact affected providers
